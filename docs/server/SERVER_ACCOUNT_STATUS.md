## 📝 API 接口

### 1. 生成服务器账号
```
POST /v1/server/account/generate
Authorization: Bearer {token}

Response:
{
  "id": "uuid",
  "username": "user_7233165c",
  "password": "Base64密文",
  "raw_password": "aB3dE7fGhJ9k",  // 仅首次返回
  "user_id": "uuid",
  "create_time": "2026-01-24 01:30:00"
}
```

### 2. 获取账号列表
```
GET /v1/server/account?page=1&limit=10
Authorization: Bearer {token}

Response:
{
  "count": 1,
  "num": 1,
  "items": [
    {
      "id": "uuid",
      "username": "user_7233165c",
      "password": "Base64密文",
      "user_id": "uuid"
    }
  ]
}
```

### 3. 获取解密密码
```
GET /v1/server/account/{id}/password
Authorization: Bearer {token}

Response:
{
  "id": "uuid",
  "username": "user_7233165c",
  "password": "Base64密文",
  "raw_password": "aB3dE7fGhJ9k",  // 解密后的密码
  "user_id": "uuid"
}
```

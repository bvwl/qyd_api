## 3. 数据库状态变化

### 初始状态（用户有 2 个旧 Token）

```
tokens 表：
┌──────┬──────────┬────────────────────────┬────────┬─────────────────────┐
│ id   │ user_id  │ token                  │ status │ create_time         │
├──────┼──────────┼────────────────────────┼────────┼─────────────────────┤
│ uuid1│ user_xxx │ eyJhbGci...old_token_1 │   1    │ 2026-01-23 08:00:00 │
│ uuid2│ user_xxx │ eyJhbGci...old_token_2 │   1    │ 2026-01-24 10:00:00 │
└──────┴──────────┴────────────────────────┴────────┴─────────────────────┘
```

### 生成新 Token 后

```
tokens 表：
┌──────┬──────────┬────────────────────────┬────────┬─────────────────────┐
│ id   │ user_id  │ token                  │ status │ create_time         │
├──────┼──────────┼────────────────────────┼────────┼─────────────────────┤
│ uuid1│ user_xxx │ eyJhbGci...old_token_1 │   2    │ 2026-01-23 08:00:00 │ ← 失效
│ uuid2│ user_xxx │ eyJhbGci...old_token_2 │   2    │ 2026-01-24 10:00:00 │ ← 失效
│ uuid3│ user_xxx │ eyJhbGci...new_token   │   1    │ 2026-01-25 12:00:00 │ ← 有效
└──────┴──────────┴────────────────────────┴────────┴─────────────────────┘
```

**变化**：
- 旧 Token 的 `status` 从 1 变为 2（失效）
- 新 Token 的 `status` 为 1（有效）
- 只有最新的 Token 可以使用

## 4. 关键代码位置

### Token 验证（`backend/app/core/verify.py`）

```python
async def get_current_user_or_token(...):
    if api_token:
        # ✅ 关键：只查询 status=1 的 Token
        token_obj = await UserToken.filter(token=api_token, status=1).first()
        if not token_obj:
            raise HTTPException(status_code=401, detail="Invalid API Token")
```

### Token 生成（`backend/app/crud/user/token.py`）

```python
async def generate_token(self, user_id: UUID) -> Out:
    # 生成新 Token
    new_token = create_access_token(data=token_data, expires_delta=315360000)
    
    # ✅ 关键：将旧 Token 设置为失效
    await UserToken.filter(user_id=user_id, status=Status.OK).update(status=Status.NOT)
    
    # 创建新 Token 记录
    res = await UserToken.create(token=new_token, user_id=user_id, status=Status.OK)
```

## 总结

✅ **Token 失效机制的核心**：

1. **验证时**：只查询 `status=1` 的 Token
2. **生成时**：将旧 Token 的 `status` 更新为 2
3. **结果**：旧 Token 无法通过验证，只有新 Token 有效

这个机制确保了每个用户同时只有一个有效的 API Token，生成新 Token 后旧 Token 自动失效。

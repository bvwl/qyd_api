# 邮件查看器功能说明

## 功能概述

新增了邮件查看器功能，允许用户查看Outlook邮箱的收件箱邮件，并支持本地缓存和搜索功能。

## 主要特性

### 1. 邮件列表查看
- 输入邮箱地址即可查看该邮箱的收件箱邮件
- 显示邮件主题、发件人、预览内容、接收时间等信息
- 支持查看邮件是否已读、是否有附件

### 2. 本地缓存（10分钟）
- **自动缓存**：首次获取邮件后，数据会自动缓存到浏览器localStorage
- **缓存有效期**：10分钟内再次查看同一邮箱，直接从缓存加载，无需重新请求
- **缓存提示**：页面会显示缓存状态和剩余有效时间
- **手动刷新**：点击"刷新"按钮可强制从服务器重新获取最新邮件

### 3. 邮件搜索功能
支持两种搜索模式：

#### 文本搜索（默认）
- 在主题、发件人、发件人名称、邮件预览中进行模糊匹配
- 不区分大小写
- 适合日常快速查找

#### 正则表达式搜索
- 点击"正则搜索"按钮切换到正则模式
- 支持复杂的模式匹配
- 示例：
  - `^Re:` - 查找所有回复邮件
  - `\d{6}` - 查找包含6位数字的邮件
  - `(urgent|important)` - 查找包含"urgent"或"important"的邮件

### 4. 邮件详情查看
- 点击"查看"按钮可查看邮件完整内容
- 支持HTML和纯文本格式
- HTML邮件使用DOMPurify进行安全清理，防止XSS攻击
- 显示完整的收件人、抄送人信息

## 后端API

### 1. 获取收件箱邮件列表
```
GET /v1/mail/outlook/inbox
参数：
  - email: 邮箱地址（必填）
  - top: 获取数量，默认50
```

### 2. 获取邮件详情
```
GET /v1/mail/outlook/message/{message_id}
参数：
  - email: 邮箱地址（必填）
  - message_id: 邮件ID（路径参数）
```

## 前端实现

### 文件结构
```
frontend/src/
├── views/Mail/
│   ├── MailList.tsx          # 邮箱管理列表
│   └── MailViewer.tsx        # 新增：邮件查看器
├── api/mail.ts               # 更新：添加新API接口
└── router/index.tsx          # 更新：添加路由
```

### 缓存机制
- 使用localStorage存储邮件数据
- 缓存键：`email_inbox_cache`
- 缓存数据结构：
  ```typescript
  {
    messages: EmailMessage[],  // 邮件列表
    timestamp: number,          // 缓存时间戳
    email: string              // 邮箱地址
  }
  ```
- 缓存有效期：10分钟（600,000毫秒）
- 自动过期：超过10分钟或切换邮箱时自动清除

### 搜索实现
- 使用useMemo优化性能，避免重复计算
- 文本搜索：使用toLowerCase()和includes()
- 正则搜索：使用RegExp对象，捕获错误并提示用户

## 使用方法

1. **访问邮件查看器**
   - 在浏览器中访问：`http://localhost:3000/mail/viewer`
   - 或通过菜单导航到"邮件查看器"

2. **查看邮件**
   - 输入邮箱地址（例如：user@example.com）
   - 点击"查看邮件"按钮
   - 等待加载完成

3. **使用缓存**
   - 首次加载后，数据会自动缓存
   - 10分钟内再次查看，直接从缓存加载
   - 页面顶部会显示"使用缓存数据（剩余 X 分钟）"

4. **刷新邮件**
   - 点击"刷新"按钮
   - 清除缓存并从服务器获取最新邮件

5. **搜索邮件**
   - 在搜索框输入关键词
   - 默认使用文本搜索
   - 点击"正则搜索"切换到正则表达式模式

6. **查看详情**
   - 点击邮件行的"查看"按钮
   - 在弹窗中查看完整邮件内容

## 安全性

- **XSS防护**：使用DOMPurify清理HTML内容
- **Token刷新**：自动刷新过期的访问令牌
- **错误处理**：完善的错误提示和异常处理

## 注意事项

1. **邮箱授权**：确保邮箱已完成OAuth2授权
2. **Token有效性**：如果Token过期，会自动尝试刷新
3. **缓存清理**：切换邮箱或刷新时会自动清除旧缓存
4. **正则表达式**：使用正则搜索时注意语法正确性
5. **浏览器兼容性**：需要支持localStorage的现代浏览器

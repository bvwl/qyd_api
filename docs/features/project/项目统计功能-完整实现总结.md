# 项目统计功能 - 完整实现总结

## 功能概述

实现项目账号更新数量的统计和展示功能，支持：

1. ✅ **数据库持久化存储** - 数据安全可靠，支持迁移
2. ✅ **Redis缓存优化** - 使用DB 10，提升查询性能
3. ✅ **定时自动同步** - AsyncIOScheduler每小时同步
4. ✅ **权限控制** - ADMIN/GM看所有，IT/MANUAL看自己的
5. ✅ **曲线图展示** - 支持最近N天的趋势分析
6. ✅ **前端集成完成** - ECharts图表，支持7/14/30/90天切换

## 数据模型

### ProjectDailyStats

```python
class ProjectDailyStats(BaseModel):
    """项目每日统计"""
    date = fields.DateField(description="统计日期", index=True)
    update_count = fields.IntField(default=0, description="当天更新的账号数量")
    project = fields.ForeignKeyField("models.ProjectInfo", related_name="daily_stats")
    
    class Meta:
        table = "project_daily_stats"
        unique_together = [("project_id", "date")]
```

### 数据库表

```sql
CREATE TABLE `project_daily_stats` (
    `id` CHAR(36) NOT NULL PRIMARY KEY,
    `date` DATE NOT NULL,
    `update_count` INT NOT NULL DEFAULT 0,
    `project_id` CHAR(36) NOT NULL,
    `create_time` DATETIME(6) NOT NULL,
    `update_time` DATETIME(6) NOT NULL,
    UNIQUE KEY (`project_id`, `date`),
    KEY (`date`),
    KEY (`project_id`, `date`)
);
```

### 3. 统计图表组件

```typescript
// src/views/Dashboard/ProjectStatsChart.tsx
import { useState, useEffect, useRef } from 'react'
import { Card, Select, Spin, Button, Space } from 'antd'
import { ReloadOutlined, ClearOutlined } from '@ant-design/icons'
import * as echarts from 'echarts'
import type { ECharts } from 'echarts'
import { getProjectStatsForDashboard, clearStatsCache } from '@/api/project'

export default function ProjectStatsChart() {
  const chartRef = useRef<HTMLDivElement>(null)
  const chartInstance = useRef<ECharts | null>(null)
  const [loading, setLoading] = useState(false)
  const [days, setDays] = useState(7)
  const [data, setData] = useState([])

  // 初始化图表
  useEffect(() => {
    if (chartRef.current && !chartInstance.current) {
      chartInstance.current = echarts.init(chartRef.current)
      
      const handleResize = () => {
        chartInstance.current?.resize()
      }
      window.addEventListener('resize', handleResize)
      
      return () => {
        window.removeEventListener('resize', handleResize)
        chartInstance.current?.dispose()
      }
    }
  }, [])

  // 加载数据
  useEffect(() => {
    loadData()
  }, [days])

  const loadData = async () => {
    try {
      setLoading(true)
      const response = await getProjectStatsForDashboard({ days })
      if (response.code === 1 && response.data) {
        setData(response.data)
        renderChart(response.data)
      }
    } catch (error) {
      console.error('加载统计数据失败:', error)
    } finally {
      setLoading(false)
    }
  }

  const renderChart = (statsData) => {
    if (!chartInstance.current || !statsData || statsData.length === 0) {
      return
    }

    const option = {
      title: {
        text: '项目账号更新趋势',
        left: 'center'
      },
      tooltip: {
        trigger: 'axis',
        axisPointer: { type: 'cross' }
      },
      legend: {
        data: statsData.map(item => item.project_name),
        top: 35,
        type: 'scroll'
      },
      xAxis: {
        type: 'category',
        boundaryGap: false,
        data: statsData[0]?.dates || []
      },
      yAxis: {
        type: 'value',
        name: '更新数量',
        minInterval: 1
      },
      series: statsData.map(item => ({
        name: item.project_name,
        type: 'line',
        data: item.counts,
        smooth: true,
        emphasis: { focus: 'series' }
      }))
    }

    chartInstance.current.setOption(option, true)
  }

  return (
    <Card
      title="项目账号更新趋势"
      extra={
        <Space>
          <Select
            value={days}
            onChange={setDays}
            style={{ width: 120 }}
            options={[
              { label: '最近7天', value: 7 },
              { label: '最近14天', value: 14 },
              { label: '最近30天', value: 30 },
              { label: '最近90天', value: 90 }
            ]}
          />
          <Button icon={<ReloadOutlined />} onClick={loadData} loading={loading}>
            刷新
          </Button>
          {/* 管理员可见 */}
          <Button icon={<ClearOutlined />} onClick={handleClearCache} loading={loading}>
            清除缓存
          </Button>
        </Space>
      }
    >
      <Spin spinning={loading}>
        <div ref={chartRef} style={{ width: '100%', height: 400 }} />
      </Spin>
    </Card>
  )
}
```

## 故障排查

### 问题1: 定时任务未执行

**检查**:
```bash
grep "同步项目统计数据" backend/logs/scheduler.log
```

**解决**:
- 确保 `ENABLE_STATS_SYNC=1`
- 重启后端服务

### 问题2: 数据不准确

**检查**:
```sql
-- 查看统计表
SELECT * FROM project_daily_stats WHERE date = CURDATE();

-- 对比账号表
SELECT project_id, COUNT(*) 
FROM project_account 
WHERE DATE(update_time) = CURDATE() 
GROUP BY project_id;
```

**解决**:
- 手动触发同步: `POST /v1/project/stats/sync`
- 清除缓存: `POST /v1/project/stats/cache/clear`

### 问题3: Redis故障

**影响**: 查询变慢，但数据不会丢失

**解决**:
- 数据存储在数据库中，Redis恢复后自动重建缓存
- 临时禁用Redis: `REDIS_ENABLED=0`

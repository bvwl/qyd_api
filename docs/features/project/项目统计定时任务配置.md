# 项目统计定时任务配置

## 功能说明

使用 `AsyncIOScheduler` 定时同步项目统计数据，从 `project_account` 表统计每天的账号更新数量，写入 `project_daily_stats` 表。

## 配置方式

### 1. 环境变量配置

在 `backend/.env` 文件中添加以下配置：

```env
# 是否启用项目统计数据自动同步: 1=启用, 0=禁用
ENABLE_STATS_SYNC=1

# 项目统计数据同步间隔（分钟），默认60分钟
STATS_SYNC_INTERVAL_MINUTES=60
```

### 2. 配置说明

| 配置项 | 说明 | 默认值 | 推荐值 |
|--------|------|--------|--------|
| `ENABLE_STATS_SYNC` | 是否启用统计同步 | `1` | `1`（启用） |
| `STATS_SYNC_INTERVAL_MINUTES` | 同步间隔（分钟） | `60` | `30-120` |

**推荐配置**:
- **开发环境**: `STATS_SYNC_INTERVAL_MINUTES=30`（30分钟）
- **生产环境**: `STATS_SYNC_INTERVAL_MINUTES=60`（1小时）
- **高频更新**: `STATS_SYNC_INTERVAL_MINUTES=15`（15分钟）

## 定时任务实现

### 代码位置

`backend/app/main.py` 中的 `lifespan` 函数：

```python
# 可选：自动同步项目统计数据
enable_stats_sync = os.getenv("ENABLE_STATS_SYNC", "1").lower() in ("1", "true", "yes")
if enable_stats_sync:
    from app.utils.stats_sync import scheduled_sync_stats
    
    stats_sync_interval = int(os.getenv("STATS_SYNC_INTERVAL_MINUTES", "60"))
    scheduler.add_job(
        scheduled_sync_stats,
        IntervalTrigger(minutes=stats_sync_interval),
        id="sync_project_stats",
        name="同步项目统计数据",
        coalesce=True,
        misfire_grace_time=300,  # 5分钟容错
    )
    scheduler_logger.info(f"已注册定时任务: 每 {stats_sync_interval} 分钟同步项目统计数据")
```

### 任务函数

`backend/app/utils/stats_sync.py` 中的 `scheduled_sync_stats` 函数：

```python
async def scheduled_sync_stats():
    """
    定时同步统计数据（每小时执行一次）
    """
    try:
        await sync_today_stats()
    except Exception as e:
        print(f"❌ 定时同步失败: {e}")
        import traceback
        traceback.print_exc()
```

## 工作流程

### 1. 启动时

```
应用启动
  ↓
读取环境变量 ENABLE_STATS_SYNC
  ↓
如果启用 = 1
  ↓
注册定时任务到 AsyncIOScheduler
  ↓
启动调度器
  ↓
定时任务开始运行
```

### 2. 定时执行

```
定时触发（每N分钟）
  ↓
执行 scheduled_sync_stats()
  ↓
调用 sync_today_stats()
  ↓
查询今天更新的所有账号
  ↓
按项目统计更新数量
  ↓
更新 project_daily_stats 表
  ↓
清除相关Redis缓存
  ↓
完成
```

### 3. 关闭时

```
应用关闭信号
  ↓
停止调度器（不接受新任务）
  ↓
等待正在执行的任务完成
  ↓
关闭数据库连接
  ↓
优雅退出
```

## 性能优化

### 1. 调整同步间隔

根据业务需求调整同步间隔：

- **低频更新**（每天更新几次）: `STATS_SYNC_INTERVAL_MINUTES=120`（2小时）
- **中频更新**（每小时更新几次）: `STATS_SYNC_INTERVAL_MINUTES=60`（1小时）
- **高频更新**（实时性要求高）: `STATS_SYNC_INTERVAL_MINUTES=15`（15分钟）

### 2. 数据库优化

### 3. 监控同步性能

```python
import time

async def scheduled_sync_stats():
    """定时同步统计数据（带性能监控）"""
    start_time = time.time()
    try:
        await sync_today_stats()
        elapsed = time.time() - start_time
```

## 故障排查

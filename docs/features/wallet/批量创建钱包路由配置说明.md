# 批量创建钱包路由配置说明

## 问题原因

前端页面无法加载的原因是：**后端数据库中没有注册批量创建钱包的路由权限**。

系统使用基于后端路由权限的菜单系统，所有前端路由都需要在后端数据库中注册，并绑定到相应的角色。

FROM frontend_route 
WHERE path = '/project/wallet/batch-create';

SELECT COUNT(*) as has_permission
FROM role_route_rel rr
JOIN role r ON rr.role_id = r.id

## 数据库表结构

### frontend_route 表

存储所有前端路由信息：

```sql
CREATE TABLE frontend_route (
    id CHAR(36) PRIMARY KEY,
    name VARCHAR(100) NOT NULL,           -- 路由名称
    path VARCHAR(255) NOT NULL,           -- 路由路径
    title VARCHAR(100) NOT NULL,          -- 菜单标题
    component VARCHAR(100),               -- 组件名称
    icon VARCHAR(50),                     -- 图标
    sort INT DEFAULT 0,                   -- 排序
    parent_id CHAR(36),                   -- 父路由ID
    route_type INT DEFAULT 1,             -- 路由类型（1:菜单 2:按钮）
    is_hidden TINYINT DEFAULT 0,          -- 是否隐藏
    status INT DEFAULT 1,                 -- 状态
    create_time DATETIME,
    update_time DATETIME
);
```

### role_route_rel 表

存储角色和路由的关联关系：

```sql
CREATE TABLE role_route_rel (
    role_id CHAR(36) NOT NULL,            -- 角色ID
    route_id CHAR(36) NOT NULL,           -- 路由ID
    PRIMARY KEY (role_id, route_id)
);
```

## 常见问题

### Q1: 为什么前端路由配置了但页面不显示？

**A**: 因为系统使用基于后端路由权限的菜单系统，需要：
1. 在后端数据库中注册路由
2. 将路由绑定到角色
3. 重新登录加载最新权限

### Q2: 如何添加新的路由？

**A**: 按以下步骤：
1. 在 `backend/db/init_routes.py` 中添加路由配置
2. 运行 `python backend/db/init_routes.py` 初始化路由
3. 运行 `python backend/db/bind_admin_routes.py` 绑定到ADMIN角色
4. 在前端添加路由和组件
5. 重启后端，刷新前端，重新登录

### Q3: 如何验证路由是否配置成功？

**A**: 
1. 查询数据库: `SELECT * FROM frontend_route WHERE path = '/your/path'`
2. 检查角色权限: 查询 `role_route_rel` 表
3. 重新登录后查看菜单是否显示

### Q4: 为什么重新登录后还是看不到菜单？

**A**: 可能的原因：
1. 浏览器缓存未清除 → 强制刷新（Ctrl+Shift+R）
2. 后端服务未重启 → 重启后端服务
3. 路由未绑定到角色 → 运行 `bind_admin_routes.py`

### Q5: 如何给其他角色添加此路由权限？

**A**: 
1. 在权限管理页面手动分配
2. 或修改 `backend/db/bind_gm_routes.py` 等脚本

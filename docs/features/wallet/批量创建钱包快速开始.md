# 批量创建钱包 - 快速开始

## 安装依赖

### 前端
```bash
cd frontend
npm install
```

### 后端
```bash
cd backend
pip install -r requirements.txt
```

## 启动服务

### 1. 启动后端
```bash
cd backend
python start.py
```

### 2. 启动前端
```bash
cd frontend
npm run dev
```

## 核心功能

| 功能 | 说明 |
|------|------|
| 批量创建 | 一次创建1-100个钱包 |
| 临时存储 | 前端临时存储10分钟 |
| 倒计时 | 实时显示剩余时间 |
| 下载Excel | 导出为Excel文件（明文） |
| 保存数据库 | 加密保存到数据库 |
| 权限控制 | 只有ADMIN可访问 |

## API接口

### 批量创建
```bash
POST /api/v1/project/wallet/batch
Authorization: Bearer {TOKEN}

{
  "project_name": "项目名称",
  "chain": "eth",
  "count": 10,
  "remark": "备注"
}
```

### 保存到数据库
```bash
POST /api/v1/project/wallet/upsert

{
  "private_key": "加密的私钥",
  "public_key": "公钥",
  "mnemonic": "加密的助记词",
  "chain": "eth",
  "remark": "备注"
}
```

## 注意事项

1. **临时存储**: 创建的钱包只在前端临时存储10分钟
2. **及时保存**: 请及时下载或保存到数据库
3. **安全性**: 下载的Excel包含明文，请妥善保管
4. **权限**: 只有ADMIN可以访问此功能

## 常见问题

### Q: 如何修改临时存储时间？
A: 修改 `WalletBatchCreate.tsx` 中的 `setCountdown(600)` 值（单位：秒）

### Q: 如何支持更多链类型？
A: 在表单的链类型Select中添加新选项，后端已支持

### Q: 下载的Excel在哪里？
A: 浏览器默认下载目录，文件名格式：`钱包_{链类型}_{时间戳}.xlsx`

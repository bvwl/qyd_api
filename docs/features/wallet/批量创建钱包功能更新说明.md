# 批量创建钱包功能 - 更新说明

## 更新内容

### 1. 自动保存到数据库 ✓

**之前的设计**:
- 钱包只在前端临时存储10分钟
- 需要用户手动点击"保存到数据库"按钮

**现在的设计**:
- 批量创建的钱包**自动保存到数据库**
- 同时在前端临时显示10分钟（方便用户下载）
- 10分钟后前端临时数据清除，但数据库中的钱包仍然保留

### 2. 简化用户操作 ✓

**移除的功能**:
- ❌ "保存到数据库"按钮（不再需要）
- ❌ 保存相关的状态和函数

**保留的功能**:
- ✓ 批量创建钱包
- ✓ 10分钟临时显示
- ✓ 下载为Excel文件
- ✓ 敏感信息显示/隐藏
- ✓ 一键复制

### 3. 更新说明文字 ✓

**功能说明**:
```
1. 支持批量创建 ETH 和 Solana 钱包
2. 私钥和助记词使用 AES 加密存储到数据库
3. 创建后的钱包会自动保存到数据库，同时在前端临时显示 10 分钟
4. 可以下载为 Excel 文件（包含明文私钥和助记词），请妥善保管
5. 10分钟后前端临时数据会清除，但数据库中的钱包仍然保留
```

**警告提示**:
```
前端临时数据即将过期，请尽快下载Excel文件！数据库中的钱包不受影响。
```

## 常见问题

### Q1: 批量创建的钱包保存在哪里？
**A**: 自动保存到数据库的 `project_wallet` 表中。

### Q2: 10分钟后数据会丢失吗？
**A**: 不会。只是前端临时显示数据会清除，数据库中的钱包永久保留。

### Q3: 如何查看已创建的钱包？
**A**: 访问"项目管理" → "项目钱包"页面，可以查看所有钱包。

### Q4: 为什么要10分钟临时显示？
**A**: 方便用户立即下载Excel文件。10分钟后清除是为了安全考虑。

### Q5: 下载的Excel文件包含什么？
**A**: 包含所有钱包的明文数据（序号、链、公钥、私钥、助记词、备注、创建时间）。

### Q6: 如何导出已保存的钱包？
**A**: 在"项目钱包"页面，ADMIN可以查看所有钱包（自动解密），然后手动导出。

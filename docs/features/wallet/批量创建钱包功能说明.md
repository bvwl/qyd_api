# 批量创建钱包功能说明

## 功能概述

实现了批量创建区块链钱包的功能，支持以太坊（ETH）和Solana两种链。所有私钥和助记词都经过AES加密存储，只有管理员可以查看解密后的敏感信息。

## 核心特性

### 1. 批量创建
- 一次可创建 1-100 个钱包
- 支持 ETH（以太坊）和 Solana 两种链
- 自动生成私钥、公钥和助记词
- 私钥和助记词自动加密存储到数据库

### 2. 加密机制
- **加密算法**: AES-128-CBC
- **加密密钥**: MD5(项目名称 + "9527")
- **加密向量**: MD5("9527" + 项目名称) 取前16位
- **编码方式**: Base64

### 3. 权限控制
- **创建权限**: 只有 ADMIN 角色可以批量创建钱包
- **查看权限**: 
  - ADMIN: 查询时自动解密，可以看到明文私钥和助记词
  - 其他角色: 只能看到加密后的数据

### 4. 查看钱包列表

```bash
GET /api/v1/project/wallet?chain=eth&limit=20
Authorization: Bearer {Token}
```

**查询参数**:
- `chain`: 链类型过滤（eth/solana）
- `project_id`: 项目ID过滤
- `page`: 页码（默认1）
- `limit`: 每页数量（默认10，最大1000）
- `res_count`: 是否返回总数（true/false）

**权限说明**:
- ADMIN: 返回所有钱包，自动解密
- GM: 返回所有钱包，不解密
- IT/MANUAL: 只返回分配给该用户的项目的钱包，不解密

## 安全说明

### 1. 加密存储
- 所有私钥和助记词都经过AES加密后存储到数据库
- 每个项目使用不同的加密密钥（基于项目名称）
- 数据库中不存储任何明文敏感信息

### 2. 权限控制
- 只有ADMIN角色可以批量创建钱包
- 只有ADMIN角色可以查看解密后的私钥和助记词
- 其他角色只能看到加密后的数据

### 3. 密钥管理
- 加密密钥基于项目名称动态生成
- 不需要额外的密钥管理系统
- **重要**: 项目名称是解密的关键，必须妥善保管

### 4. 最佳实践
- 定期备份钱包数据
- 限制ADMIN角色的分配
- 记录所有钱包访问日志
- 使用HTTPS传输数据

## 常见问题

### Q1: 如何修改加密密钥规则？
**A**: 修改 `backend/app/core/tools.py` 中的 `aes_encrypt_wallet` 和 `aes_decrypt_wallet` 函数。

**注意**: 修改后需要重新加密所有现有数据！

### Q2: 忘记项目名称怎么办？
**A**: 项目名称是解密的关键，如果忘记则无法解密。

**建议**:
- 创建时记录项目名称
- 使用项目ID关联到项目表
- 定期备份项目名称映射关系

### Q3: 如何支持更多链类型？
**A**: 
1. 在 `backend/app/clients/wallet.py` 中添加新的钱包创建方法
2. 在 `batch_create` 方法中添加对应的处理逻辑

### Q4: 如何导出钱包数据？
**A**: 使用管理员账号调用钱包列表API，会自动解密所有数据，然后可以导出为CSV或Excel。

### Q5: 为什么不关联项目表？
**A**: 为了灵活性，钱包创建时不自动关联项目。如果需要关联，可以在创建后手动更新 `project_id` 字段。

## 技术实现

### 加密工具

```python
# backend/app/core/tools.py

def aes_encrypt_wallet(plaintext: str, project_name: str) -> str:
    """加密钱包敏感数据"""
    key_string = f"{project_name}9527"
    key = hashlib.md5(key_string.encode('utf-8')).digest()
    
    iv_string = f"9527{project_name}"
    iv = hashlib.md5(iv_string.encode('utf-8')).digest()[:16]
    
    cipher = AES.new(key, AES.MODE_CBC, iv)
    padded_plaintext = pad(plaintext.encode('utf-8'), AES.block_size)
    ciphertext = cipher.encrypt(padded_plaintext)
    
    return base64.b64encode(ciphertext).decode('utf-8')
```

### 钱包客户端

```python
# backend/app/clients/wallet.py

class WalletClient:
    async def eth_create(self):
        """创建ETH钱包"""
        Account.enable_unaudited_hdwallet_features()
        account, mnemonic = Account.create_with_mnemonic()
        return account._private_key.hex(), account.address, mnemonic
    
    async def solana_create(self):
        """创建Solana钱包"""
        signing = SigningKey.generate()
        public_key = base58.b58encode(signing.verify_key.encode()).decode('utf-8')
        private_key = base58.b58encode(signing._signing_key).decode('utf-8')
        return private_key, public_key, None
```

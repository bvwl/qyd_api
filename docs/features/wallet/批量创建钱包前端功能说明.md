## 页面功能详解

### 1. 创建表单

**字段说明**:
- **项目名称**: 必填，用于加密私钥和助记词
- **链类型**: 必填，支持ETH和Solana
- **创建数量**: 必填，范围1-100
- **备注**: 可选，最多200字符

**表单验证**:
- 项目名称不能为空
- 链类型必须选择
- 创建数量必须在1-100之间

### 2. 临时存储（10分钟）

**倒计时功能**:
- 创建成功后自动开始10分钟倒计时
- 实时显示剩余时间（分:秒格式）
- 剩余时间小于1分钟时显示红色警告
- 时间到期后自动清空临时数据

**警告提示**:
- 剩余时间小于1分钟时显示警告提示
- 提醒用户尽快下载或保存

### 3. 表格展示

**列说明**:
- **序号**: 自动编号
- **链**: 显示链类型（大写）
- **公钥**: 可显示/隐藏，支持复制
- **私钥**: 可显示/隐藏，支持复制
- **助记词**: 可显示/隐藏，支持复制（Solana无助记词）
- **创建时间**: 显示创建时间

**交互功能**:
- 点击眼睛图标切换显示/隐藏
- 点击复制图标复制内容
- 分页显示，每页10条

### 4. 下载功能

**下载为Excel**:
- 文件名格式: `钱包_{链类型}_{时间戳}.xlsx`
- 包含所有字段（明文）
- 自动设置列宽
- 包含序号、链、公钥、私钥、助记词、备注、创建时间

**Excel结构**:
```
序号 | 链 | 公钥 | 私钥 | 助记词 | 备注 | 创建时间
-----|-----|------|------|--------|------|----------
1    | ETH | 0x... | 0x... | word... | 测试 | 2026-01-25...
```

### 5. 保存到数据库

**保存逻辑**:
- 使用upsert接口（根据公钥唯一性）
- 批量保存所有钱包
- 保存成功后清空临时数据
- 清除倒计时

**保存后**:
- 临时数据被清空
- 倒计时停止
- 表单重置
- 可以在"项目钱包"页面查看

### 6. 权限控制

**访问权限**:
- 只有ADMIN角色可以访问
- 非ADMIN访问时显示权限不足提示

**功能权限**:
- 创建: 仅ADMIN
- 下载: 仅ADMIN
- 保存: 仅ADMIN

## 技术实现

### 1. 倒计时实现
```typescript
// 使用useEffect和setTimeout实现倒计时
useEffect(() => {
  if (countdown > 0) {
    timerRef.current = setTimeout(() => {
      setCountdown(countdown - 1)
    }, 1000)
  } else if (countdown === 0 && wallets.length > 0) {
    message.warning('临时数据已过期')
    setWallets([])
  }
  
  return () => {
    if (timerRef.current) {
      clearTimeout(timerRef.current)
    }
  }
}, [countdown, wallets.length])
```

### 2. Excel导出实现
```typescript
import * as XLSX from 'xlsx'

const handleDownload = () => {
  // 准备数据
  const exportData = wallets.map((wallet, index) => ({
    '序号': index + 1,
    '链': wallet.chain,
    '公钥': wallet.public_key,
    '私钥': wallet.private_key,
    '助记词': wallet.mnemonic || '-',
    '备注': wallet.remark || '-',
    '创建时间': wallet.create_time
  }))
  
  // 创建工作簿
  const ws = XLSX.utils.json_to_sheet(exportData)
  const wb = XLSX.utils.book_new()
  XLSX.utils.book_append_sheet(wb, ws, '钱包列表')
  
  // 下载
  XLSX.writeFile(wb, fileName)
}
```

### 3. 批量保存实现
```typescript
const handleSaveToDatabase = async () => {
  // 批量保存
  const promises = wallets.map(wallet => 
    upsertProjectWallet({
      private_key: wallet.private_key,
      public_key: wallet.public_key,
      mnemonic: wallet.mnemonic,
      chain: wallet.chain,
      remark: wallet.remark
    })
  )
  
  await Promise.all(promises)
  
  // 清空临时数据
  setWallets([])
  setCountdown(0)
}
```

## 注意事项

### 1. 临时存储
- 创建的钱包只在前端临时存储10分钟
- 刷新页面会丢失临时数据
- 请及时下载或保存到数据库

### 2. 安全性
- 下载的Excel文件包含明文私钥和助记词
- 请妥善保管下载的文件
- 建议下载后立即删除浏览器下载记录

### 3. 权限
- 只有ADMIN角色可以访问此页面
- 非ADMIN访问会显示权限不足提示

### 4. 数据保存
- 保存到数据库后，私钥和助记词会被加密
- 只有ADMIN查询时会自动解密
- 其他角色只能看到加密数据

### 5. 浏览器兼容性
- 建议使用Chrome、Firefox、Edge等现代浏览器
- Excel下载功能需要浏览器支持Blob和File API

## 常见问题

### Q1: 为什么临时存储只有10分钟？
**A**: 为了安全考虑，避免敏感数据长时间存储在前端内存中。10分钟足够用户下载或保存数据。

### Q2: 刷新页面后数据会丢失吗？
**A**: 是的，临时数据只存储在内存中，刷新页面会丢失。请在刷新前下载或保存。

### Q3: 下载的Excel文件安全吗？
**A**: Excel文件包含明文数据，请妥善保管。建议：
- 下载后立即移动到安全位置
- 使用加密软件加密文件
- 不要通过网络传输

### Q4: 保存到数据库后还能下载吗？
**A**: 保存后临时数据会被清空，但可以在"项目钱包"页面查看和导出。

### Q5: 如何批量导出已保存的钱包？
**A**: 在"项目钱包"页面，ADMIN可以查看所有钱包（自动解密），然后可以手动导出。

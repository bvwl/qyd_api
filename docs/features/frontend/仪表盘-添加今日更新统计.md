# 仪表盘 - 添加今日更新统计

## 功能说明

在仪表盘的统计卡片中新增"今日更新"统计，显示当天所有项目账号的更新数量。

## 实现方案

### 1. 数据来源

使用现有的项目统计API，查询最近1天的数据：

```typescript
getProjectStatsForDashboard({ days: 1 })
```

返回数据格式：
```json
{
  "code": 1,
  "data": [{
    "project_id": "total",
    "project_name": "总计",
    "dates": ["2026-01-25"],
    "counts": [15]  // 今天的更新数量
  }]
}
```

### 2. 前端修改

**文件**: `frontend/src/views/Dashboard/index.tsx`

#### 2.1 添加导入

```typescript
import { RiseOutlined } from '@ant-design/icons'
import { getProjectStatsForDashboard } from '@/api/project'
```

#### 2.2 更新接口定义

```typescript
interface DashboardStats {
  user_count?: number
  project_count: number
  account_count: number
  today_update_count: number  // 新增
  role: string
  user_email: string
  user_nickname: string
}
```

#### 2.3 修改数据加载逻辑

在 `fetchData` 函数中，为每个角色添加今日统计查询：

```typescript
// 管理员
const [usersRes, projectsRes, accountsRes, todayStatsRes] = await Promise.all([
  getUserList({ page: 1, limit: 1, res_count: true }),
  getProjectList({ page: 1, limit: 1, res_count: true }),
  getProjectAccountList({ page: 1, limit: 1, res_count: true }),
  getProjectStatsForDashboard({ days: 1 }),  // 新增
])

// 获取今天的更新数量
if (todayStatsRes.code === 1 && todayStatsRes.data && todayStatsRes.data.length > 0) {
  today_update_count = todayStatsRes.data[0].counts[0] || 0
}
```

#### 2.4 添加统计卡片

```typescript
<Col xs={24} sm={12} lg={stats.user_count !== undefined ? 5 : 6}>
  <Card>
    <Statistic
      title="今日更新"
      value={stats.today_update_count}
      prefix={<RiseOutlined />}
      valueStyle={{ color: '#fa8c16' }}
    />
  </Card>
</Col>
```

### 3. 布局调整

为了容纳新的统计卡片，调整了列宽：

**管理员（5个卡片）**：
- 用户总数：`lg={5}` (20%)
- 项目总数：`lg={5}` (20%)
- 账户总数：`lg={5}` (20%)
- 今日更新：`lg={5}` (20%)
- 在线用户：`lg={4}` (20%)

**非管理员（4个卡片）**：
- 项目总数：`lg={6}` (25%)
- 账户总数：`lg={6}` (25%)
- 今日更新：`lg={6}` (25%)
- （无在线用户卡片）

## 功能特点

### 1. 权限控制

- **ADMIN**: 显示所有项目的今日更新总和
- **GM**: 显示所有项目的今日更新总和
- **IT/MANUAL**: 显示自己项目的今日更新总和

### 2. 实时性

- 数据来自 `project_daily_stats` 表
- 每60分钟自动同步一次
- 支持手动刷新（刷新页面）

### 3. 性能优化

- 使用 `Promise.all` 并行请求
- 查询最少数据（days=1）
- 利用现有的缓存机制（5分钟）

### 4. 视觉设计

- **图标**: `RiseOutlined` (上升箭头)
- **颜色**: `#fa8c16` (橙色)
- **位置**: 在"账户总数"和"在线用户"之间

## 使用场景

### 1. 快速了解今日活跃度

用户打开仪表盘，立即看到今天更新了多少账号，快速了解系统活跃度。

### 2. 对比历史数据

结合下方的统计图表，可以对比今天和历史的更新趋势。

### 3. 监控异常

如果今日更新数量异常（过高或过低），可以及时发现问题。

## 数据流程

```
用户打开仪表盘
    ↓
fetchData() 函数执行
    ↓
并行请求多个API
    ├─ getUserList (管理员)
    ├─ getProjectList
    ├─ getProjectAccountList
    └─ getProjectStatsForDashboard({ days: 1 })  ← 新增
         ↓
    后端查询 project_daily_stats 表
         ↓
    返回今天的统计数据
         ↓
    提取 counts[0] (今天的数量)
         ↓
    设置 today_update_count
         ↓
    渲染统计卡片
```

## API调用示例

### 请求

```bash
GET /v1/project/stats/dashboard?days=1
Authorization: Bearer <token>
```

### 响应

```json
{
  "code": 1,
  "message": "成功",
  "data": [{
    "project_id": "total",
    "project_name": "总计",
    "dates": ["2026-01-25"],
    "counts": [15]
  }]
}
```

### 数据提取

```typescript
const today_update_count = todayStatsRes.data[0].counts[0] || 0
// today_update_count = 15
```

## 错误处理

```typescript
getProjectStatsForDashboard({ days: 1 }).catch(() => ({ 
  code: 0, 
  data: [] 
}))

// 如果请求失败，today_update_count 默认为 0
if (todayStatsRes.code === 1 && todayStatsRes.data && todayStatsRes.data.length > 0) {
  today_update_count = todayStatsRes.data[0].counts[0] || 0
}
```

## 测试验证

### 1. 管理员用户

- 应该看到5个统计卡片
- "今日更新"显示所有项目的总和
- 数值应该与统计图表的今天数据一致

### 2. 普通用户

- 应该看到4个统计卡片（无"用户总数"和"在线用户"）
- "今日更新"显示自己项目的总和
- 数值应该与统计图表的今天数据一致

### 3. 无数据情况

- 如果今天没有更新，显示 0
- 不会报错或显示异常

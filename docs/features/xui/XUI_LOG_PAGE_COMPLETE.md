# XUI 操作日志页面完成

## 完成内容

### 1. 前端页面 (`frontend/src/views/Xui/XuiOperationLog.tsx`)

创建了完整的 XUI 操作日志页面,包含以下功能:

#### 功能特性
- ✅ 显示失败的操作日志列表
- ✅ 按操作类型筛选(添加账号、移除账号、批量添加、同步入站)
- ✅ 显示详细的错误信息
- ✅ 显示重试次数和最后重试时间
- ✅ 一键重试单个失败操作(仅管理员)
- ✅ 批量重试所有失败操作(仅管理员)
- ✅ 刷新功能
- ✅ 分页显示
- ✅ 权限控制

#### 页面布局
```
┌─────────────────────────────────────────────────────────┐
│ XUI 操作日志                                              │
│ 说明: 记录 XUI 账号添加、删除等操作的日志,失败的操作可以一键重试 │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ [操作类型▼] [刷新] [批量重试失败操作]                      │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ 操作类型 │ 状态 │ 入站信息 │ 账号用户名 │ 错误信息 │ 操作 │
├─────────────────────────────────────────────────────────┤
│ 添加账号 │ 失败 │ 192.168.1.1:8080 │ user1 │ 解密密码失败 │ [重试] │
│ 批量添加 │ 失败 │ 192.168.1.2:8080 │ user2 │ XUI面板返回失败 │ [重试] │
└─────────────────────────────────────────────────────────┘
```

#### 表格列
1. **操作类型**: 带颜色标签显示(添加账号/移除账号/批量添加/同步入站)
2. **状态**: 带颜色标签显示(成功/失败/重试中/待处理)
3. **入站信息**: 显示 host:port
4. **账号用户名**: 显示账号的用户名
5. **错误信息**: 红色显示错误详情
6. **重试次数**: 居中显示
7. **最后重试时间**: 显示最后一次重试的时间
8. **创建时间**: 显示日志创建时间
9. **操作**: 重试按钮(仅失败状态且管理员可见)

#### 颜色方案
- **操作类型**:
  - 添加账号: 蓝色 (blue)
  - 移除账号: 橙色 (orange)
  - 批量添加: 紫色 (purple)
  - 同步入站: 绿色 (green)

- **状态**:
  - 成功: 绿色 (success)
  - 失败: 红色 (error)
  - 重试中: 蓝色动画 (processing)
  - 待处理: 灰色 (default)

### 5. API 集成

页面使用以下 API:
- `GET /v1/xui/account/failed-logs` - 获取失败日志列表
- `POST /v1/xui/account/retry-failed/{log_id}` - 重试单个失败操作
- `POST /v1/xui/account/batch-retry-failed` - 批量重试失败操作

## 使用流程

### 1. 查看失败日志
1. 进入"XUI管理" -> "操作日志"
2. 查看所有失败的操作记录
3. 可以按操作类型筛选
4. 查看详细的错误信息

### 2. 重试单个失败操作
1. 找到需要重试的日志记录
2. 点击"重试"按钮
3. 系统会重新执行该操作
4. 成功后日志状态会更新为"成功"
5. 失败则更新错误信息和重试次数

### 3. 批量重试所有失败操作
1. 点击页面顶部的"批量重试失败操作"按钮
2. 确认操作
3. 系统会自动重试所有失败的添加账号操作
4. 显示成功和失败的统计信息

## 权限控制

- **查看日志**: 所有登录用户
- **重试操作**: 仅 ADMIN 角色
- **批量重试**: 仅 ADMIN 角色

## 日志记录时机

系统会在以下情况自动记录日志:

1. **添加账号**
   - 成功 → 记录 SUCCESS 日志
   - 解密密码失败 → 记录 FAILED 日志
   - XUI 面板返回失败 → 记录 FAILED 日志
   - 其他异常 → 记录 FAILED 日志

2. **批量添加**
   - 每个账号单独记录日志
   - 批量操作本身也记录一条汇总日志

3. **重试操作**
   - 开始重试 → 更新状态为 RETRYING
   - 重试成功 → 更新状态为 SUCCESS
   - 重试失败 → 更新状态为 FAILED,记录新错误

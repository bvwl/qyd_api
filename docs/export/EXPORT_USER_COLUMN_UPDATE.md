# 导出功能更新 - 添加用户列

## 更新内容

在导出所有项目统计的 Excel 文件中，新增"所属用户"列，显示项目关联的用户昵称。

## 更新说明

### 1. 新增列

**列名**: 所属用户  
**位置**: 第3列（项目ID之后，账号数量之前）  
**内容**: 项目关联的用户昵称

### 2. 数据显示规则

#### 2.1 单个用户
```
张三
```

#### 2.2 多个用户
多个用户用逗号和空格分隔：
```
张三, 李四, 王五
```

#### 2.3 未分配用户
如果项目没有关联任何用户：
```
未分配
```

#### 2.4 用户无昵称
如果用户没有设置昵称，显示邮箱：
```
user@example.com
```

### 3. 技术实现

#### 3.1 预加载用户数据

使用 `prefetch_related` 预加载用户关联数据，避免 N+1 查询：

```python
projects = await ProjectInfo.all().prefetch_related('users')
```

#### 3.2 获取用户昵称

遍历项目关联的用户，获取昵称或邮箱：

```python
user_nicknames = []
if project.users:
    for user in project.users:
        if user.nickname:
            user_nicknames.append(user.nickname)
        else:
            user_nicknames.append(user.email)  # 如果没有昵称，使用邮箱

users_str = ", ".join(user_nicknames) if user_nicknames else "未分配"
```

#### 3.3 Excel 列宽调整

所属用户列宽度设置为 25：

```python
column_widths = [20, 38, 25, 12, 12, 12, 12, 12, 12, 12, 12, 12]
```

#### 3.4 对齐方式

前3列（项目名称、项目ID、所属用户）左对齐，其他列居中：

```python
cell.alignment = Alignment(
    horizontal="left" if col_num <= 3 else "center", 
    vertical="center"
)
```

### 6. 性能优化

#### 6.1 预加载关联数据

使用 `prefetch_related('users')` 一次性加载所有项目的用户关联数据，避免在循环中多次查询数据库。

**优化前**（N+1 查询）:
```python
projects = await ProjectInfo.all()
for project in projects:
    users = await project.users.all()  # 每个项目都查询一次
```

**优化后**（1次查询）:
```python
projects = await ProjectInfo.all().prefetch_related('users')
for project in projects:
    users = project.users  # 直接使用预加载的数据
```

#### 6.2 性能对比

假设有 100 个项目：
- 优化前：101 次数据库查询（1次查项目 + 100次查用户）
- 优化后：2 次数据库查询（1次查项目 + 1次查所有用户关联）

性能提升约 **50倍**！

### 7. 数据库关系

项目和用户是**多对多关系**：

```python
# ProjectInfo 模型
users: ManyToManyRelation["UserInfo"] = fields.ManyToManyField(
    "models.UserInfo",
    related_name="projects",
    through="project_user_rel",
    description="项目与用户关联",
)
```

**关系说明**:
- 一个项目可以关联多个用户
- 一个用户可以关联多个项目
- 通过中间表 `project_user_rel` 维护关系

### 9. 注意事项

1. **用户昵称优先**:
   - 优先显示用户昵称
   - 如果没有昵称，显示邮箱
   - 确保总是有内容显示

2. **多用户显示**:
   - 使用逗号和空格分隔（`, `）
   - 保持格式统一
   - 便于阅读

3. **未分配处理**:
   - 明确标识未分配项目
   - 便于管理员识别和处理

4. **列宽适配**:
   - 所属用户列宽度为 25
   - 足够显示 2-3 个中文昵称
   - 如果用户更多，Excel 会自动换行

5. **性能考虑**:
   - 使用预加载避免 N+1 查询
   - 大量项目时性能依然良好
   - 建议项目数量 < 1000

### 10. 常见问题

#### Q1: 用户列显示不完整怎么办？

**原因**: 用户太多，列宽不够

**解决**: 
- 在 Excel 中手动调整列宽
- 或者在代码中增加列宽：
  ```python
  column_widths = [20, 38, 35, 12, ...]  # 将25改为35
  ```

#### Q2: 为什么有些项目显示邮箱而不是昵称？

**原因**: 用户没有设置昵称

**解决**: 
- 在用户管理页面为用户设置昵称
- 或者接受显示邮箱（邮箱也是唯一标识）

#### Q3: 未分配的项目如何分配用户？

**解决**: 
- 在项目管理页面编辑项目
- 选择要分配的用户
- 保存后重新导出即可看到更新

#### Q4: 多个用户的顺序是什么？

**说明**: 
- 按照数据库中的关联顺序
- 通常是添加关联的时间顺序
- 如需特定顺序，可以在代码中排序

# 权限管理界面 - 使用说明

## 🎉 功能已完成

权限管理界面已经创建完成，管理员可以通过可视化界面管理各个角色的权限。

## 📍 访问方式

### 方式1：通过菜单访问
1. 登录系统
2. 点击左侧菜单"用户管理"
3. 点击"权限管理"子菜单

### 方式2：直接访问URL
```
http://127.0.0.1:5173/user/permission
```

## 🎯 界面功能

### 左侧：角色列表
- 显示所有系统角色
- 支持搜索功能
- 点击角色可查看和编辑其权限
- 选中的角色会高亮显示

### 右侧：权限配置
- 树形结构展示所有菜单和功能
- 支持勾选/取消勾选权限
- 显示权限类型标签（菜单/按钮/接口）
- 显示权限标识
- 提供全选/取消全选快捷操作
- 实时显示已选择的权限数量

## 📊 当前权限配置

系统已为4个角色配置了典型的权限：

### 1. 管理员（ADMIN）
- ✅ 所有权限（28个）
- 可以访问所有菜单和功能

### 2. 项目管理员（GM）
- ✅ 仪表盘
- ✅ 项目管理（全部功能）
- ✅ 服务器管理（查看）
- 共10个权限

### 3. 技术人员（IT）
- ✅ 仪表盘
- ✅ 服务器管理（全部功能）
- ✅ 邮箱管理（全部功能）
- 共9个权限

### 4. 手动操作员（MANUAL）
- ✅ 仪表盘
- ✅ 项目列表（只读）
- ✅ 服务器列表（只读）
- 共3个权限

## 🚀 快速开始

### 1. 查看角色权限
```bash
# 访问权限管理页面
http://127.0.0.1:5173/user/permission

# 点击左侧任意角色，查看其权限配置
```

### 2. 修改角色权限
```bash
# 1. 选择要修改的角色
# 2. 在右侧权限树中勾选或取消勾选权限
# 3. 点击"保存权限"按钮
```

### 3. 测试权限
```bash
# 1. 使用不同角色的账号登录
# 2. 查看左侧菜单是否按权限显示
# 3. 测试页面内的按钮是否按权限显示
```

## 💻 技术实现

### 前端文件
```
frontend/src/views/User/PermissionManage.tsx  - 权限管理页面
frontend/src/router/index.tsx                 - 路由配置
frontend/src/components/Layout/index.tsx      - 菜单配置
```

### 后端文件
```
backend/db/init_routes.py                     - 路由初始化
backend/demo_permission_setup.py              - 权限配置演示
backend/app/apis/v1/user/route.py             - 路由API
backend/app/apis/v1/user/role.py              - 角色API
```

### API端点
```
GET  /v1/user/route/tree          - 获取路由树
GET  /v1/user/route/user-routes   - 获取用户路由权限
GET  /v1/user/role/{id}/routes    - 获取角色路由权限
POST /v1/user/role/{id}/routes    - 设置角色路由权限
```

## 📖 使用场景

### 场景1：为新员工创建角色并分配权限

```bash
# 1. 在"角色管理"页面创建新角色
访问：http://127.0.0.1:5173/user/role
点击"创建角色"，输入角色信息

# 2. 在"权限管理"页面配置权限
访问：http://127.0.0.1:5173/user/permission
选择新创建的角色
勾选需要的权限
点击"保存权限"

# 3. 在"用户管理"页面为用户分配角色
访问：http://127.0.0.1:5173/user/list
编辑用户，选择角色
```

### 场景2：调整现有角色权限

```bash
# 1. 访问权限管理页面
http://127.0.0.1:5173/user/permission

# 2. 选择要调整的角色
点击左侧角色列表中的角色

# 3. 修改权限
勾选或取消勾选权限项

# 4. 保存
点击"保存权限"按钮
```

### 场景3：临时收回某个功能的权限

```bash
# 例如：临时禁止所有非管理员删除用户

# 1. 访问权限管理页面
# 2. 依次选择每个非管理员角色
# 3. 取消勾选"用户管理 > 用户列表 > 删除按钮"
# 4. 保存权限
```

## 🔧 故障排查

### 问题1：看不到权限管理菜单

**解决方法：**
```bash
# 1. 重新初始化路由
cd backend
python db/init_routes.py

# 2. 刷新浏览器页面
# 3. 如果还是看不到，检查当前用户是否有权限
```

### 问题2：保存权限失败

**检查：**
1. 浏览器控制台是否有错误
2. 后端服务是否正常运行
3. 当前用户是否有权限管理权限

### 问题3：权限配置后不生效

**解决方法：**
1. 让用户退出登录
2. 重新登录
3. 权限会立即生效

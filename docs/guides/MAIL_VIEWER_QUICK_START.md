# 邮件查看器 - 快速启动指南

## 🚀 快速开始

### 1. 安装依赖（必须）
```bash
./install_mail_viewer_deps.sh
```

或者手动安装：
```bash
cd frontend
npm install dompurify@^3.0.8 isomorphic-dompurify@^2.9.0
npm install --save-dev @types/dompurify@^3.0.5
```

### 2. 重启前端（如果正在运行）
```bash
# 停止当前前端进程（Ctrl+C）
cd frontend
npm run dev
```

### 3. 访问页面
```
http://localhost:3000/mail/viewer
```

## 📧 使用方法

### 查看邮件
1. 输入邮箱地址（例如：user@example.com）
2. 点击"查看邮件"按钮
3. 等待加载完成

### 使用缓存
- 首次加载后，数据会自动缓存10分钟
- 页面顶部显示：`使用缓存数据（剩余 X 分钟）`
- 点击"刷新"按钮可强制更新

### 搜索邮件
- **文本搜索**（默认）：输入关键词，如"重要"、"会议"
- **正则搜索**：点击切换按钮，输入正则表达式
  - `^Re:` - 查找回复邮件
  - `\d{6}` - 查找包含6位数字的邮件
  - `(urgent|important)` - 查找紧急或重要邮件

### 查看详情
- 点击邮件行的"查看"按钮
- 在弹窗中查看完整内容

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 📦 本地缓存 | 10分钟自动缓存，避免重复请求 |
| 🔍 智能搜索 | 支持文本和正则表达式搜索 |
| 🔒 安全渲染 | HTML邮件使用DOMPurify防XSS |
| 🔄 自动刷新 | Token过期自动刷新 |
| 💾 状态提示 | 显示缓存状态和剩余时间 |

## 🎯 搜索示例

### 文本搜索
```
test          → 查找包含"test"的邮件
重要通知       → 查找包含"重要通知"的邮件
john@example  → 查找特定发件人
```

### 正则搜索
```
^Re:          → 所有回复邮件
^Fwd:         → 所有转发邮件
\d{4}-\d{2}   → 包含日期格式的邮件
@gmail\.com   → Gmail发件人
(会议|meeting) → 包含"会议"或"meeting"
```

## ⚠️ 注意事项

1. **邮箱授权**：确保邮箱已完成OAuth2授权
2. **Token有效性**：Token过期会自动刷新
3. **缓存清理**：切换邮箱或超过10分钟自动清除
4. **正则语法**：注意正则表达式语法正确性

## 🐛 常见问题

### Q: 提示"Token刷新失败"？
A: 需要重新授权邮箱，在邮箱管理页面完成OAuth2授权

### Q: 缓存不生效？
A: 检查浏览器是否支持localStorage，或清除浏览器缓存

### Q: 正则搜索报错？
A: 检查正则表达式语法，特殊字符需要转义

### Q: 邮件内容显示不全？
A: 点击"查看"按钮查看完整内容

# 用户信息修改功能

## 修改时间
2026-01-22

## 修改内容

### 1. 在Layout组件中添加修改信息功能

在用户下拉菜单中添加了"修改信息"选项，点击后弹出修改信息的对话框。

#### 功能特性：
- **昵称修改**：用户可以修改自己的昵称（可选）
- **邮箱修改**：用户可以修改自己的邮箱（可选）
- **密码修改**：用户可以选择修改密码（可选）
- **按需更新**：只传递修改过的字段给后端
- **密码确认**：修改密码时需要确认两次输入一致
- **表单验证**：
  - 邮箱格式验证（如果填写）
  - 密码最少6个字符（如果填写）
  - 确认密码必须与新密码一致

#### 修改的文件：
- `frontend/src/components/Layout/index.tsx`
  - 添加了 `profileModalVisible` 状态管理弹窗显示
  - 添加了 `form` 表单实例
  - 在用户菜单中添加了"修改信息"选项
  - 实现了 `handleUpdateProfile` 函数处理信息更新
  - 只传递修改过的字段给后端
  - 添加了修改信息的Modal组件

### 2. 在UserStore中添加setUserInfo方法

为了支持更新本地用户信息，在用户store中添加了 `setUserInfo` 方法。

#### 修改的文件：
- `frontend/src/store/useUserStore.ts`
  - 在接口定义中添加了 `setUserInfo` 方法
  - 实现了 `setUserInfo` 方法用于更新本地用户信息

### 3. 使用现有的updateUser API

使用了已有的 `updateUser` API接口来更新用户信息：
- 接口路径：`PUT /v1/user/user/{id}`
- 支持部分更新（只传递修改的字段）
- 支持更新昵称、邮箱和密码
- 使用JWT认证，确保用户只能修改自己的信息

## 使用流程

1. 用户点击右上角头像，展开下拉菜单
2. 点击"修改信息"选项
3. 在弹出的对话框中：
   - 修改昵称（可选，不修改则留空）
   - 修改邮箱（可选，不修改则留空，需要有效的邮箱格式）
   - 输入新密码（可选，不修改则留空）
   - 确认新密码（如果修改密码）
4. 点击"确定"按钮提交修改
5. 修改成功后，本地用户信息自动更新

## 技术实现

### 按需更新逻辑
前端会检查每个字段是否被修改：
- 昵称：与当前用户昵称对比，不同才传递
- 邮箱：与当前用户邮箱对比，不同才传递
- 密码：如果填写了新密码，则传递

只有实际修改的字段才会发送给后端，符合后端可选参数的设计。

如果没有任何修改，会提示"没有修改任何信息"。

## 安全性

- 使用JWT认证，确保用户身份
- 密码修改需要确认两次输入
- 邮箱格式验证，确保输入有效的邮箱地址
- 后端会验证用户权限，确保只能修改自己的信息
- 只传递修改的字段，减少不必要的数据传输

## 注意事项

1. 所有字段都是可选的，只修改需要修改的字段即可
2. 修改密码时，两次输入必须一致
3. 邮箱必须符合邮箱格式（如果填写）
4. 密码最少6个字符（如果填写）
5. 修改成功后，本地用户信息会立即更新，无需重新登录
6. 如果没有修改任何信息就点击确定，会提示"没有修改任何信息"

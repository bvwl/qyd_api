# 用户管理功能快速指南

## 访问页面

启动前端服务后，使用管理员账号登录，即可在左侧菜单看到"用户管理"菜单，包含以下子菜单:

1. **用户列表** - `/user/list`
2. **角色管理** - `/user/role`
3. **路由管理** - `/user/route`
4. **Token管理** - `/user/token`
5. **操作日志** - `/user/log`

## 功能说明

### 1. 角色管理
- 查看所有角色
- 创建新角色（需要管理员权限）
- 编辑角色信息（需要管理员权限）
- 删除角色（需要管理员权限）
- 角色标识创建后不可修改

**系统预设角色**:
- ADMIN（管理员）- 红色标记
- GM（游戏管理）- 橙色标记
- IT（技术人员）- 蓝色标记
- MANUAL（普通用户）- 默认标记

### 2. 路由管理
- 查看所有前端路由
- 创建新路由（需要管理员权限）
- 编辑路由信息（需要管理员权限）
- 删除路由（需要管理员权限）
- 配置路由的菜单显示、缓存、固定等属性

**路由配置项**:
- 路由名称: 唯一标识
- 路由路径: 前端访问路径
- 菜单标题: 显示在菜单中的名称
- 组件路径: 对应的前端组件
- 菜单图标: 菜单图标名称
- 排序: 数字越小越靠前
- 是否隐藏菜单: 控制是否在菜单中显示
- 是否缓存页面: 控制页面是否缓存
- 是否固定标签页: 控制标签页是否固定

### 3. Token管理
- 查看所有API Token
- 创建新Token（需要管理员权限）
- 修改Token状态（需要管理员权限）
- 删除Token（需要管理员权限）
- 一键复制Token到剪贴板

**Token说明**:
- Token用于API访问认证
- 每个Token关联一个用户
- 可以设置Token状态（正常/异常）
- Token显示时只显示前20个字符，点击复制按钮可复制完整Token

### 4. 操作日志
- 查看所有用户操作日志（只读）
- 按用户ID搜索日志
- 查看操作类型、描述、IP地址、User-Agent等信息

**操作类型**:
- 登录 - 蓝色标记
- 登出 - 默认标记
- 创建 - 绿色标记
- 更新 - 橙色标记
- 删除 - 红色标记
- 查询 - 青色标记

## 权限说明

- **管理员（ADMIN）**: 拥有所有权限，可以进行增删改查操作
- **其他角色**: 只能查看数据，不能进行增删改操作

## 使用示例

### 创建新角色
1. 点击"角色管理"菜单
2. 点击"新增角色"按钮
3. 填写角色名称、角色标识、描述
4. 点击"确定"保存

### 创建新路由
1. 点击"路由管理"菜单
2. 点击"新增路由"按钮
3. 填写路由信息（必填项：路由名称、路由路径、菜单标题）
4. 配置可选项（图标、排序、缓存等）
5. 点击"确定"保存

### 管理Token
1. 点击"Token管理"菜单
2. 查看所有Token列表
3. 点击复制按钮可复制Token
4. 可以修改Token状态或删除Token

### 查看操作日志
1. 点击"操作日志"菜单
2. 查看所有操作记录
3. 可以在搜索框输入用户ID进行筛选
4. 点击"搜索"按钮或按回车键执行搜索

## 注意事项

1. 删除操作会弹出确认对话框，请谨慎操作
2. 角色标识创建后不可修改，请确保正确填写
3. 路由名称是唯一标识，不能重复
4. Token一旦创建，请妥善保管
5. 操作日志只能查看，不能修改或删除

## 常见问题

**Q: 为什么我看不到"新增"、"编辑"、"删除"按钮？**
A: 这些操作需要管理员权限，请使用管理员账号登录。

**Q: 如何复制Token？**
A: 在Token列表中，每个Token后面都有一个复制按钮，点击即可复制到剪贴板。

**Q: 操作日志可以删除吗？**
A: 操作日志是只读的，不能修改或删除，用于审计和追溯。

**Q: 角色标识为什么不能修改？**
A: 角色标识是系统内部使用的唯一标识，修改可能导致权限系统异常，因此创建后不允许修改。

### 基本规则
- **ADMIN角色**：可以操作所有数据（创建、查询、修改、删除）

## 技术实现

### 权限检查函数

在 `backend/app/core/verify.py` 中实现了以下权限检查函数：

1. **`check_project_access(project_id, current_user)`**
   - 检查用户是否有权限访问指定项目
   - ADMIN和GM可以访问所有项目
   - 其他角色只能访问自己关联的项目

2. **`check_data_permission(current_user)`**
   - 检查用户的数据权限
   - 返回None表示可以查看所有数据（ADMIN/GM）
   - 返回用户ID表示只能查看自己关联的数据

### API修改

每个需要权限控制的API端点都添加了：

1. **导入权限检查函数**：
   ```python
   from app.core.verify import check_project_access, get_current_user
   ```

2. **添加current_user参数**：
   ```python
   current_user: dict = Depends(get_current_user)
   ```

3. **在操作前检查权限**：
   ```python
   # 创建时检查项目权限
   if item.project_id:
       await check_project_access(item.project_id, current_user)
   
   # 查询/修改时先获取资源，再检查权限
   obj = await crud.get(id)
   if obj.project_id:
       await check_project_access(obj.project_id, current_user)
   ```

# 菜单修复验证指南

## 🎯 验证目标
确认管理员可以看到"邮件查看器"菜单，并且能正常访问。

## ✅ 验证步骤

### 1. 刷新前端页面
如果前端正在运行，刷新浏览器页面（Ctrl+R 或 Cmd+R）

### 2. 检查左侧菜单
查看左侧导航栏，应该能看到：
```
📧 邮箱管理
  ├─ 邮箱列表
  ├─ 邮件查看器  ← 新增的菜单
  └─ Outlook授权
```

### 3. 点击"邮件查看器"
- 点击菜单项
- 应该跳转到 `/mail/viewer` 页面
- 页面应该正常显示邮件查看器界面

### 4. 测试功能
在邮件查看器页面：
1. 输入邮箱地址
2. 点击"查看邮件"按钮
3. 验证功能是否正常

## 🔍 问题排查

### 问题1：看不到"邮件查看器"菜单

**可能原因**：
- 前端缓存未刷新
- 用户不是管理员

**解决方法**：
1. 硬刷新浏览器（Ctrl+Shift+R 或 Cmd+Shift+R）
2. 清除浏览器缓存
3. 确认登录的是管理员账号（zhiyu）

### 问题2：点击菜单后404

**可能原因**：
- 前端路由未配置

**解决方法**：
1. 检查 `frontend/src/router/index.tsx` 是否包含 `/mail/viewer` 路由
2. 重启前端服务

### 问题3：页面显示错误

**可能原因**：
- 依赖未安装

**解决方法**：
```bash
./install_mail_viewer_deps.sh
```

## 如何修改角色权限

1. 使用管理员账号登录
2. 进入"用户管理" → "权限管理"
3. 选择要配置的角色
4. 勾选该角色可以访问的菜单
5. 点击"保存"按钮
6. 该角色的用户需要重新登录才能看到新的菜单

## 技术实现

### 后端API
- `GET /v1/user/route/user-routes` - 获取当前用户的路由权限

### 前端实现
- `frontend/src/components/Layout/index.tsx` - 动态菜单加载
- `frontend/src/api/user.ts` - API调用封装

### 工作流程
1. 用户登录后，前端调用 `/v1/user/route/user-routes` API
2. 后端根据用户的角色返回该用户有权限的路由列表
3. 前端根据返回的路由数据动态生成菜单
4. 只显示用户有权限的菜单项

## 注意事项

1. **重新登录生效**：修改权限后，用户需要重新登录才能看到新的菜单
2. **路由保护**：即使用户直接访问URL，后端也会验证权限
3. **按钮权限**：页面内的按钮权限需要使用 `Permission` 组件单独控制

# 邮件查看器最终更新

## 更新内容

### 1. 默认显示最近10条邮件
- 修改默认获取数量从 50 条改为 10 条
- 用户可以通过分页选择器选择 10/20/50 条

### 2. 优化内容预览
- 移除 HTML 标签，只显示纯文本
- 移除多余的空白字符
- 预览长度限制为 80 个字符
- 超过 80 字符显示省略号

### 3. 改进查看详情功能
- 按钮文字改为"查看详情"（更明确）
- 详情弹窗宽度增加到 1000px（更好地显示 HTML 邮件）
- 详情内容区域高度增加到 600px
- 优化 HTML 内容显示样式
- 添加更好的文字换行和行高

### 4. 支持内容查询
- 保留了文本搜索功能
- 保留了正则表达式搜索功能
- 可以在主题、发件人、内容中搜索

## 功能说明

### 邮件列表显示

| 列名 | 宽度 | 说明 |
|------|------|------|
| 主题 | 300px | 显示邮件主题，无主题显示"(无主题)" |
| 发件人 | 250px | 显示发件人邮箱地址 |
| 内容预览 | 自适应 | 显示前80个字符的纯文本预览 |
| 操作 | 120px | "查看详情"按钮 |

### 分页设置

- 默认每页显示：10 条
- 可选每页数量：10、20、50 条
- 显示总数统计

### 搜索功能

#### 文本搜索
在主题、发件人、内容中搜索包含指定文本的邮件（不区分大小写）

#### 正则搜索
使用正则表达式进行高级搜索，例如：
- `microsoft|amazon` - 搜索包含 microsoft 或 amazon 的邮件
- `^\d+` - 搜索以数字开头的内容
- `@\w+\.com` - 搜索特定域名的邮件

### 查看详情

点击"查看详情"按钮后：
1. 弹出详情窗口（1000px 宽）
2. 显示邮件主题和发件人
3. 完整显示 HTML 格式的邮件内容
4. 内容区域可滚动（最高 600px）
5. HTML 内容经过 DOMPurify 安全清理

## 使用示例

### 1. 查看最近10封邮件

```
1. 输入邮箱地址：zhiyu918918@outlook.com
2. 点击"查看邮件"按钮
3. 显示最近10封邮件
```

### 2. 搜索特定内容

```
1. 在搜索框输入关键词，例如："Microsoft"
2. 自动过滤显示包含该关键词的邮件
```

### 3. 使用正则搜索

```
1. 点击"文本搜索"按钮切换到"正则搜索"
2. 输入正则表达式，例如："account.*security"
3. 显示匹配的邮件
```

### 4. 查看邮件详情

```
1. 点击某封邮件的"查看详情"按钮
2. 弹出窗口显示完整的邮件内容
3. HTML 邮件会正确渲染样式
```

## 技术细节

### HTML 内容清理

使用 DOMPurify 清理 HTML 内容，允许：
- `<style>` 标签（保留邮件样式）
- `target` 属性（链接可以在新窗口打开）
- `style` 属性（保留内联样式）

### 内容预览处理

```typescript
const plainText = text?.replace(/<[^>]*>/g, '').replace(/\s+/g, ' ').trim() || ''
const preview = plainText.substring(0, 80)
```

1. 移除所有 HTML 标签
2. 将多个空白字符替换为单个空格
3. 去除首尾空白
4. 截取前 80 个字符

### 缓存机制

- 缓存时间：10 分钟
- 缓存键：`email_inbox_cache`
- 缓存内容：邮件列表数据
- 刷新按钮：强制从服务器获取最新数据

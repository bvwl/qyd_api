### 查询流程

```
┌─────────────────────────────────────────────────────────────────┐

                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                 后端 get_role_routes()                            │
│                                                                   │
│  步骤1：查询叶子节点                                              │
│  ┌────────────────────────────────────────┐                     │
│  │ SELECT * FROM role_route_rel           │                     │
│  │ WHERE role_id = 'manual'               │                     │
│  └────────────────────────────────────────┘                     │
│  结果：['country-id', 'group-id', 'list-id']                     │
│                                                                   │
│  步骤2：收集父节点ID                                              │
│  ┌────────────────────────────────────────┐                     │
│  │ parent_ids = {r.parent_id for r in     │                     │
│  │              leaf_routes if r.parent_id}│                     │
│  └────────────────────────────────────────┘                     │
│  结果：{'server-mgmt-id'}                                        │
│                                                                   │
│  步骤3：查询父节点                                                │
```

## 节点类型判断

```
┌─────────────────────────────────────────────────────────────────┐
│                      节点类型判断                                 │
└─────────────────────────────────────────────────────────────────┘

                    ┌─────────────┐
                    │   节点      │
                    └──────┬──────┘
                           │
              ┌────────────┴────────────┐
              │                         │
              ▼                         ▼
    ┌─────────────────┐       ┌─────────────────┐
    │ parent_id != None│       │ parent_id == None│
    └─────────────────┘       └─────────────────┘
              │                         │
              ▼                         │
    ┌─────────────────┐                │
    │   叶子节点      │                │
    │   (保存)        │                │
    └─────────────────┘                │
                                       │
                          ┌────────────┴────────────┐
                          │                         │
                          ▼                         ▼
                ┌─────────────────┐       ┌─────────────────┐
                │ route_type       │       │ route_type      │
                │ == MENU          │       │ != MENU         │
                └─────────────────┘       └─────────────────┘
                          │                         │
                          ▼                         ▼
                ┌─────────────────┐       ┌─────────────────┐
                │   父节点        │       │   叶子节点      │
                │   (不保存)      │       │   (保存)        │
                └─────────────────┘       └─────────────────┘

示例：

服务器管理
├── parent_id: None
├── route_type: MENU
└── 结果: 父节点（不保存）❌

国家管理
├── parent_id: server-mgmt-id
└── 结果: 叶子节点（保存）✅

创建按钮
├── parent_id: country-id
└── 结果: 叶子节点（保存）✅

顶级接口
├── parent_id: None
├── route_type: API
└── 结果: 叶子节点（保存）✅
```

## 对比：错误方案 vs 正确方案

### 错误方案（前端自动添加父节点）

```
用户取消"国家管理"
    ↓
Tree 返回: ['server-mgmt-id', 'group-id', 'list-id']
    ↓
前端 getAllParentKeys(): 
    ['server-mgmt-id', 'group-id', 'list-id']
    ↑ 父节点已经在，不需要添加
    ↓
保存: ['server-mgmt-id', 'group-id', 'list-id']
    ↓
❌ 问题：无法区分父节点和子节点
❌ 问题：无法单独取消子菜单
```

### 正确方案（后端过滤父节点）

```
用户取消"国家管理"
    ↓
Tree 返回: ['server-mgmt-id', 'group-id', 'list-id']
    ↓
前端直接发送: ['server-mgmt-id', 'group-id', 'list-id']
    ↓
后端过滤父节点: ['group-id', 'list-id']
    ↓
保存: ['group-id', 'list-id']
    ↓
查询时自动补全: ['server-mgmt-id', 'group-id', 'list-id']
    ↓
✅ 正确：可以单独取消子菜单
✅ 正确：父节点自动显示/隐藏
```

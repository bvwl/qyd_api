## 测试步骤

### 1. 清除浏览器缓存
```
1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"
```

或者：
```
1. 退出登录
2. 清除浏览器缓存
3. 重新登录
```

### 2. 查看控制台日志
打开浏览器控制台（F12），应该看到：
```
管理员用户，使用默认完整菜单
```

### 3. 检查菜单

### Q: 为什么我看不到邮件查看器？
A: 
1. 确认你是用管理员账号登录（zhiyu）
2. 清除浏览器缓存并重新登录

1. 点击"邮箱管理"展开菜单

A: 
1. 确认前端路由已配置
2. 检查 `frontend/src/router/index.tsx`
3. 重启前端服务
